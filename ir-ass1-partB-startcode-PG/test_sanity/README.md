# Postgraduate Public Sanity Checks

Run from the repository root:

```bash
python -m test_sanity.check_submission
```

The sanity checker verifies the required environment, imports, interfaces, and a small set of public cases. Passing it is required for runnability, but it does not guarantee full marks. The grading tests include additional cases.

For import or module errors, see [Python Project Imports and Running Modules](https://rmit.instructure.com/courses/157398/pages/python-project-imports-and-running-modules).
